# Security Policy

## Supported versions

Security fixes are made for the latest released version only.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/innuto/icon-ribbon-gradle-plugin/security/advisories/new)
(the **Security** tab → **Report a vulnerability**).

Include what you can: affected version, a description of the issue and how to reproduce it.
You can expect a first reply within a week. Once a fix is released, the advisory is published
with credit to you, unless you'd rather stay anonymous.
